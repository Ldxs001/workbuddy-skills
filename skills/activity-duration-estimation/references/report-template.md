# HTML评估报告模板

> 本文件说明HTML评估报告模板的结构和使用方式。

---

## 模板定位

本技能每次完成估算后，提供生成自包含HTML评估报告的能力。报告包含：
- 完整的估算过程和数据
- 专业图表（概率密度柱状图 + 累计概率折线图）
- 结构化表格
- 结果解读和分析建议

---

## 模板文件

模板文件位于 `scripts/templates/` 下：

| 文件 | 说明 |
|------|------|
| `scripts/templates/report-template.html` | 标准报告模板（蓝紫→蓝绿色系） |

## 填充规则

模板使用数据占位符和JS动态填充。执行AI在使用时：

1. **读取模板文件** — 获取HTML骨架
2. **替换占位符** — 用实际计算数据替换 `{{PLACEHOLDER}}`
3. **调用JS函数** — 使用模板自带的JS函数填充图表数据
4. **输出完整文件** — 写入独立HTML文件

---

## 模板特性

| 特性 | 说明 |
|------|------|
| **自包含** | 一个HTML文件，无外部依赖 |
| **图表** | 使用SVG/canvas原生绘图，无需加载库 |
| **配色** | 专业配色方案（蓝紫→蓝绿渐变） |
| **表格** | 结构化数据表，可读性强 |
| **图表样式** | 柱状图（概率密度） + 折线图（累计概率） |
| **布局** | 两栏/全宽混合布局，适应屏幕 |
| **字体** | 系统字体栈，中文完美支持 |

## 使用方式

执行AI在Phase 3生成报告时：

```python
# 1. 读取模板（从安装目录）
import os
SKILL_DIR = os.path.dirname(os.path.abspath(__file__))  # 指向 scripts/
template_path = os.path.join(SKILL_DIR, "templates", "report-template.html")
with open(template_path, "r", encoding="utf-8") as f:
    html = f.read()

# 2. 填入动态数据
html = html.replace("{{TASK_NAME}}", "软件开发项目工期估算")
html = html.replace("{{METHOD_USED}}", "β分布 + 蒙特卡洛模拟")
# ... 更多替换

# 3. 输出文件到数据目录 output/
DATA_DIR = os.path.join(os.path.dirname(SKILL_DIR), ".standardization", "activity-duration-estimation", "output")
os.makedirs(DATA_DIR, exist_ok=True)
output_path = os.path.join(DATA_DIR, "estimate_report.html")
with open(output_path, "w", encoding="utf-8") as f:
    f.write(html)
```
