# 语义拆分技能 (Semantic Split)

## 概述

将用户自然语言输入拆分为结构化的需求块，确保 AI 准确理解用户全部诉求，不丢失任何细节。

**核心逻辑**：识别主语划分块 → 提取目的/行为/动机 → 结构化输出 → 用户确认 → 交给大模型执行

---

## 语义拆分规则

### 一、划分块（Block）

**识别主语，划分语义块：**

| 主语类型 | 识别方式 | 块标记 |
|---------|---------|--------|
| 用户（"我"） | 说话者本人 | `块1：用户` |
| AI助手（"你"） | 执行者、帮助者 | `块2：执行者` |
| 第三方（"他/她/它"） | 提及的其他角色 | `块3：第三方-N` |

**块内元素提取：**

每个块需提取三类信息：

| 元素 | 定义 | 示例 |
|-----|------|-----|
| **目的 (Purpose)** | 最终要达成的目标 | "明天要介绍产品" |
| **行为/诉求 (Request)** | 需要执行的具体操作或交付物 | "做一个PPT"、"写一份报告" |
| **动机 (Motivation)** | 为什么会产生这个需求 | "PPT太难做了"、"时间紧迫" |

### 二、诉求聚合（Request Aggregation）

将同一目的下的所有诉求点聚合，包括：
- 核心诉求（主要交付物）
- 支撑信息（背景、条件、约束）
- 附加细节（特征、规格、要求）

---

## 执行流程

### 步骤 1：接收输入

```
用户输入 → 保留原文，记录原始输入
```

### 步骤 2：识别主语 & 划分块

扫描文本，识别所有主语代词和指代：
- 第一人称：我、咱们、俺
- 第二人称：你、您、咱们
- 第三人称：他、她、它、以及具体名称

每个独立主语 = 一个块

### 步骤 3：提取块内元素

对每个块，逐句分析：

```
对于 [主语] 说的每句话：
  → 目的：这句话要达成什么？（找"为了"、"要"、"想"等关键词）
  → 行为：需要做什么具体操作？（找动词）
  → 动机：为什么会这么说？（找原因、背景、情绪）
```

### 步骤 4：结构化输出

按以下格式输出：

```
┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃  语义拆分结果                                              ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

【原始输入】
[用户原话完整引用]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【拆分结果】

## 块 N：[主语名称]
  角色：[用户/执行者/第三方]
  目的：[该主语要达成的核心目标]
  诉求：
    1. [诉求点1 - 核心交付物]
    2. [诉求点2 - 支撑信息/细节]
    3. [诉求点3 - ...]
  动机：[产生该需求的背景/原因/情绪]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【确认询问】
以上拆分是否完整准确？如有遗漏或错误，请补充或纠正。
```

### 步骤 5：用户确认

- 如有遗漏 → 用户补充 → 更新结构
- 如全部正确 → 进入步骤 6

### 步骤 6：输出结构化结果

确认无误后，输出标准化的结构化结果供大模型使用：

```json
{
  "blocks": [
    {
      "id": 1,
      "subject": "用户",
      "role": "requester",
      "purpose": "[目的]",
      "requests": ["[诉求1]", "[诉求2]", ...],
      "motivation": "[动机]"
    },
    {
      "id": 2,
      "subject": "执行者",
      "role": "executor",
      "purpose": "[目的]",
      "requests": ["[行为1]", "[行为2]", ...],
      "motivation": "[触发条件/动机]"
    }
  ],
  "raw_input": "[原始输入]"
}
```

## 常见主语映射表

| 文本中的词 | 映射为 | 备注 |
|-----------|-------|------|
| 我、咱们、俺 | 用户 | 说话者本人 |
| 你、您 | 执行者 | AI助手 |
| 我们 | 用户（含其团队） | 视为用户群体 |
| 他/她/它 + [名称] | 第三方 | 需标注具体身份 |
| [公司/产品名] | 第三方 | 实体对象 |

---

## 边界情况处理

| 情况 | 处理方式 |
|-----|---------|
| 单用户无明确主语 | 默认主语为"用户"，生成1个块 |
| 多个并列诉求 | 在同一块内以编号列表呈现 |
| 隐含目的（没说"为了X"） | 根据上下文推断，在动机中标注"[推断]" |
| 情绪/语气词 | 归入动机，标注"[情绪]" |
| 时间约束 | 归入目的或诉求中的约束条件 |
| 预算/资源限制 | 归入诉求中的约束条件 |

---

## 触发条件

当用户出现以下意图时，必须触发本技能：

1. 提出任务请求（"帮我做..."、"请你..."）
2. 表达需求（"我需要..."、"我想..."）
3. 委托工作（"交给你了..."、"你去..."）
4. 描述问题寻求帮助（"有个问题...帮我..."）
5. 用户未明确说但有明显需求意图时

**注意**：简单问答（"今天天气怎么样"）、闲聊（"你好"）无需拆分。
