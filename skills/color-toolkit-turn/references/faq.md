# FAQ / 常见问题

## 使用注意

### Q: 技能要求 Python 版本？

A: 需要 Python ≥ 3.8，仅使用标准库（math, re, random, dataclasses, typing），无需额外 pip 安装。

### Q: 支持哪些颜色格式？

A: HEX（3/6 位）、RGB、HSL、HSV、CMYK 五种格式全支持，可互相转换。

### Q: 对比度有几种算法？

A: 四种：WCAG 2.1、APCA、CIELAB ΔE*ab、CIEDE2000，覆盖无障碍标准和专业色差需求。

## 排错指南

> 常见错误分为：**参数错误**（输入格式不正确）、**环境错误**（浏览器/文件路径）、**期望错误**（推荐不准确）。以下是各类场景的排查步骤。

### Q: 出错了怎么办？转换结果不对

A: 首先检查输入格式是否正确：HEX 需加 # 前缀，RGB/HSL/HSV 用空格或逗号分隔，CMYK 值范围 0-100。这是最常见的参数错误。

### Q: 预览页面不显示？

A: 预览生成依赖本地浏览器打开 HTML 文件，确认 HTML 文件路径正确且浏览器可访问。

### Q: 颜色推荐不准确？

A: 推荐结果依赖 LLM 语义解析，输入描述越具体越好（如"科技感 蓝色 带渐变"比"蓝色"好）。
