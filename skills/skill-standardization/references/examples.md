本文件展示各模式的完整执行示例。

## 示例 1：只读查询（readonly）

```bash
# 列出规则
$ python -m scripts.skill_audit rules --confirmed --mode readonly

-----------------------------------------------------------------
  R-01   [ERROR]  ERROR  frontmatter 字段完整性
  R-02   [ERROR]  ERROR  name 字段
  ...

共 26 条规则
```

```bash
# 输出创建模板
$ python -m scripts.skill_audit create-template --confirmed --mode readonly

======================================================================
  skill-standardization 创建模板（供 LLM 参考）
======================================================================

----------------------------------------------------------------------
  R-01 [ERROR] [ERROR] frontmatter 字段完整性
  检查：检查 SKILL.md 的 frontmatter 是否包含所有必填字段
  修正：[X] 需手动修正
  创建模板：
    ---
    name: <skill-name>
    author: <your-name>
    ...
```

## 示例 2：审计（audit）

```bash
# 全量审计
$ python -m scripts.skill_audit audit ~/.workbuddy/skills/color-toolkit --confirmed --mode audit

审查结果: color-toolkit — FAIL (1 ERROR, 1 WARN)
总计: 26 | ✅ 通过: 24 | ❌ 失败: 2

R-07     E       [ERROR] 触发条件章节质量不合格 ...
R-20     W       [WARN]  写作规范问题 ...
```

```bash
# 审计+自动修复
$ python -m scripts.skill_audit audit ~/.workbuddy/skills/color-toolkit --fix --confirmed --mode audit

=== 自动修正模式 ===
[OK] R-trigger_quality：修正 1 处
[OK] R-writing_standards：修正 0 处
[OK] 共修正 ['trigger_quality', 'writing_standards'] 处
```

```bash
# 验证双0
$ python -m scripts.skill_audit audit ~/.workbuddy/skills/color-toolkit --verify --confirmed --mode audit

[VERIFY] 验证通过：所有未通过项均为误报，达到铁律 0 ERROR 0 WARN 要求
```
