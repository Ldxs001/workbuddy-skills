## 二、Transformer 架构深度解析

Transformer 架构的提出标志着自然语言处理领域从序列模型向并行计算范式的根本性转变，奠定了当前所有大型语言模型（LLM）的技术基石。其核心创新在于完全摒弃了传统的循环神经网络（RNN）或卷积神经网络（CNN）结构，转而采用基于注意力机制的编码器 - 解码器框架，通过数学原理实现了全局依赖关系的直接建模。

自注意力机制（Self-Attention）是 Transformer 最核心的组件，它允许序列中任意两个位置直接进行信息交互，无需经过中间步骤。在计算过程中，输入向量被线性映射为查询（Query）、键（Key）和值（Value）三个矩阵。通过计算 Query 与 Key 的点积并除以缩放因子，模型能够动态评估不同词元间的相关性权重，进而对 Value 进行加权求和得到上下文感知表示。这一机制配合多头注意力（Multi-Head Attention），使得模型能够同时从不同的子空间捕捉多样的语义特征，有效解决了长距离依赖问题，彻底克服了 RNN 在处理长序列时的梯度消失与计算串行化瓶颈。

在结构层面，标准 Transformer 由多个堆叠的编码器层和解码器层组成。每一层内部包含多头自注意力模块和前馈神经网络（FFN），并通过残差连接（Residual Connection）与层归一化（Layer Normalization）技术保障深层网络的训练稳定性。虽然原始架构采用对称的双侧结构，但在大型语言模型的具体演进中，架构形式发生了分化：BERT 等模型主要利用编码器进行理解任务，而 GPT 系列则采用解码器自回归生成模式，仅保留解码器的注意力掩码机制以屏蔽未来信息。这种模块化设计赋予了极强的扩展性，使得模型参数量能够随着数据规模线性增长而不致于崩溃。

Transformer 的性能优势体现在极高的并行计算效率与泛化能力上。由于去除了序列依赖，训练过程可充分利用 GPU 的矩阵运算能力，大幅缩短了收敛时间。此外，其基于注意力权重的动态特征提取方式，使其在处理不同长度的输入时表现出良好的鲁棒性。正是这种架构的稳定性与可扩展性，使得 Transformer 能够支撑起从亿级到万亿级参数的模型扩展，成为大语言模型时代不可或缺的技术底座。后续的所有优化工作，如稀疏化、MoE 结构等，均是在此基础之上进行的改进与延伸。
