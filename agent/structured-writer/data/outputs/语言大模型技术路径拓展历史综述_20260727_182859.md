# 语言大模型技术路径拓展历史综述



## 语言大模型发展历程回顾

### 早期探索与神经网络奠基阶段

早期语言处理主要依赖基于规则的系统，其泛化能力较弱且长期维护成本较为高昂。随后统计语言模型兴起，利用语料库概率分布提升性能，但仍受限于特征工程与数据稀疏性瓶颈。深度学习引入引发关键架构变革，循环神经网络虽初步捕捉长程依赖，却面临计算效率局限。2017 年 Transformer 提出，凭借自注意力机制显著革新序列建模方式，奠定现代大模型基础。这一阶段标志着技术范式从人工规则向数据驱动、从浅层统计向深层表征学习的根本转变，为后续参数规模爆发式增长及通用人工智能探索铺平道路。
### 大模型范式确立与当前技术路径

Transformer 架构确立后，基于 Decoder-Only 的生成式模型迅速成为主流范式。核心演进遵循 Scaling Law，通过扩大参数量（已突破千亿级）与数据规模持续优化性能，涌现出稠密网络与混合专家（MoE）等变体。当前技术路径形成“预训练 - 微调 - 强化学习对齐”的标准流水线：自监督预训练构建通用知识底座，有监督微调适配任务指令，基于人类反馈的强化学习（RLHF）则解决安全性问题。这一体系实现了从专用工具向通用智能体的跨越，为 AGI 奠定基础，也标志着技术重心转向如何在有限算力下平衡规模增长与应用效能的挑战。
